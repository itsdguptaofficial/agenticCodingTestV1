# Decision Record Template

- Status: Proposed | Accepted | Deprecated | Superseded

## Context
Describe the context and problem statement.
Explain the forces at play and any technical constraints.

## Decision
State the decision that the team made.
Use the active voice.
Write in clear STE-style sentences.

## Consequences
Describe the positive and negative results of this decision.
List any trade-offs accepted by the team.
