# Project Glossary

This document defines the official terms used across the project.
Each term has exactly one meaning.

| Term | Definition |
| :--- | :--- |
| Agent | An autonomous AI assistant that performs software development tasks under human supervision. |
| Checkpoint | A git commit created to save progress before a task switch or after an atomic step. |
| Rule | A scoped configuration file in `.agents/rules/` that gives instructions to an agent. |
| STE | Simplified Technical English, a controlled writing standard that improves clarity and readability. |
| Task File | A structured markdown file in `tasks/` that records task ownership, scope, and files touched. |
| Token | A reusable CSS custom property that defines a color, font, or spacing value. |
| Decision Record | A document in `docs/decisions/` that records an architecture or design choice. |
