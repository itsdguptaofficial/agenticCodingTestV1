# Task Management

This directory contains task files for all project work.

## Core Rules
1. Create one file for each task.
2. Name task files using `T-0001-short-name.md`.
3. Fill in the "Files Touched" section before you modify any file.
   This practice prevents concurrent edit conflicts between contributors.
4. Update the task status as you make progress.
5. Close the task file when the pull request merges into `main`.
